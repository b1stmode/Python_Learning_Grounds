# Python_Learning_Grounds

A collection of small JavPython exercises and mini-projects, written manually while learning Python.

## What is this?

This is a personal learning repository, not a production project or a portfolio piece. Every exercise here was written by hand as a way to practice specific Python concepts, one at a time, and build them up gradually.

## Learning approach

The general workflow is: **learn, practice, build, review.**

Each exercise is small and focused on purpose, usually just one or two new concepts on top of what came before. The goal is to actually understand how and why the code works, not to produce the most polished solution possible.

AI is sometimes used for explanations, hints, debugging guidance, clarifying a concept or documentation reformating. It is not used to write the exercises themselves. All implementations in this repository are written manually.

## Repository structure

```
01-basics/
  001-TemperatureConverter/
    app.py
  002-TempConverterV2/
    app.py
  ...
```

Each exercise lives in its own numbered folder with a single `app.py`. The number reflects the order the exercises were written in, so the folders roughly show the progression of what was being learned at the time. Each `app.py` starts with a short header comment describing the exercise, the concepts it practices, and when it was done.

## Exercises

The exercises in `01-basics/` are intentionally small drills, not standalone apps. Some reuse the same theme as the underlying concept changes, so it's easier to see what actually changed between versions. They're meant to be read as a sequence, not judged individually.

## Philosophy

The goal isn't to write the most sophisticated code possible. It's to understand why the code works, and to gradually get better at solving problems without leaning on a generated answer.
